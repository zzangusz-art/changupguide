기기PC·휴대폰 모두 됩니다. 휴대폰은 왼쪽 위 ☰로 메뉴를 엽니다.

  3. 휴대폰 번호가 맞는지 확인하세요. 고객 통화 알림 문자가 이 번호로 갑니다.
예전 미리보기 주소(github.io)의 관리자는 쓰지 마세요. 들어가더라도 자동으로 정식 관리자로 이동합니다. 로그인은 30일 유지되니 공용 PC에서는 꼭 로그아웃하세요.

3매장 등록 (1분)

매장 관리→+ 매장 등록→지역→브랜드→월매출·권리금→사진→등록
칸입력 방법
지역 (필수)구·시 이름 일부만 쳐도 됩니다. 예) "양천" → 서울 양천구. 목록에서 고르면 ✔ 표시가 나옵니다.
브랜드목록에서 고르면 업종·지출 비율·제목이 자동으로 채워집니다. 개인 매장은 비우고 업종만 고르세요.
월매출 (필수)만원 단위 숫자. 3500 = 3,500만원. "1억2천"처럼 써도 됩니다.
월지출 · 월수익비우면 브랜드 평균 비율로 자동 계산됩니다. 실제 값을 알면 직접 고치세요. 월수익은 세전, 점주 인건비 제외 기준입니다.
권리금만원 단위. 임대보증금은 빼고 적습니다. 비우면 사이트에 "협의"로 나옵니다.
면적·층·태그·설명있으면 좋습니다. 태그(풀오토·급매·역세권 등)는 눌러서 켜고 끕니다.
제목자동으로 만들어집니다. 직접 쓰면 그 제목을 쓰고, 자동 제목으로 버튼으로 되돌릴 수 있습니다.
  • 등록: 저장 후 목록으로 갑니다. 등록 후 계속: 같은 지역으로 다음 매장을 바로 씁니다.
  • 같은 담당자·지역·브랜드·금액의 매장이 이미 있으면 중복 주의 안내가 뜹니다. 등록은 되니 확인 후 필요 없으면 삭제하세요.
  • 비슷한 매장은 기존 매장의 복제로 만든 뒤 숫자만 고치면 빠릅니다.
쓰다가 창이 닫히거나 휴대폰이 꺼져도 괜찮습니다. 입력 내용은 이 기기에 자동 보관되고, 다음에 등록 화면을 열면 "이어서 작성"으로 불러올 수 있습니다.

4사진

  1. 매장 화면 2번 칸의 📷 사진 올리기를 누릅니다. 휴대폰이면 바로 촬영할 수 있고, PC에서는 사진 파일을 칸 위로 끌어다 놓아도 됩니다.
  2. 첫 번째 사진이 대표 사진입니다. ‹ › 버튼으로 순서를 바꾸고, × 로 뺍니다.
  3. 이미 올린 사진은 ＋ 라이브러리에서 고르기로 다시 쓸 수 있습니다. 매장 브랜드 폴더가 먼저 열리고, 사진을 더블클릭하면 바로 추가됩니다.

사진 라이브러리 (팀 전체 공유 · 브랜드별 폴더)

  • 누가 올린 사진이든 팀 전체가 함께 보고 쓸 수 있습니다. 내 사진만 보려면 내 사진만을 누르세요.
  • 왼쪽 브랜드별 폴더를 누르면 그 브랜드 사진만 보입니다. 새 브랜드는 ＋ 브랜드 폴더 추가.
  • 폴더를 더블클릭하거나 사진 칸의 빈 곳을 더블클릭하면 파일 선택창이 열리고, 고르는 즉시 그 폴더로 업로드됩니다. 사진을 끌어다 놓아도 됩니다.
  • 잘못된 폴더에 들어간 사진은 사진 위 📁 버튼으로 옮깁니다.
  • 사진은 자동으로 알맞은 크기로 줄여서 올라갑니다 (한 장 최대 8MB).
  • 매장에서 쓰고 있는 사진은 라이브러리에서 지워지지 않습니다. 삭제된 매장이 쓰던 사진도 복구할 때를 위해 보호됩니다.
간판·상호·주소·전화번호가 보이는 사진은 올리지 마세요. 양도인 보안상 정확한 위치는 상담 후에만 알려드립니다.

5수정·상태 변경

  • 내가 등록한 매장(또는 매장 관리)에서 제목을 누르면 수정 화면이 열립니다. 고친 뒤 저장.
  • 다른 직원 담당 매장은 볼 수만 있습니다. 담당 변경은 메시지로 관리자에게 요청하세요.
  • 저장한 내용은 10초~1분 안에 사이트에 반영됩니다.

내가 등록한 매장 목록의 삭제를 누르면 바로 내려갑니다. 잠깐 뜨는 되돌리기로 즉시 복구할 수 있고, 나중에도 "삭제됨" 목록에서 살릴 수 있습니다.

목록의 상태 칸에서 바로 바꿀 수 있습니다. 대시보드 할 일에 "오래 그대로인 매장"이 뜨면, 바뀐 게 없을 때 변동 없음 확인만 눌러 최신 상태로 표시하세요.

6여러 명이 함께 쓸 때 — 데이터가 사라지지 않는 이유

여러 직원이 동시에 매장을 올리고 고쳐도 입력이 사라지지 않도록 아래 장치가 자동으로 동작합니다. 따로 할 일은 없고, 화면에 뜨는 안내만 따르면 됩니다.

상황시스템이 하는 일내가 할 일
다른 사람이 같은 매장을 열어 둠빨간 띠로 "○○님이 편집 중" 표시가능하면 끝날 때까지 기다리기 (같이 저장해도 괜찮음)
둘이 서로 다른 칸을 고쳐 저장두 사람 수정이 자동으로 합쳐짐 ("○○님이 바꾼 권리금과 합쳐서 저장했습니다")없음
둘이 같은 칸을 다르게 고침두 값을 보여 주고 어느 쪽을 쓸지 물어봄[확인] 내 값으로 저장 / [취소] 그대로 두고 상의
저장 중 인터넷 끊김·서버 업데이트최대 30초 동안 자동으로 다시 시도, 같은 매장이 두 번 등록되지 않음안내가 뜨면 잠시 기다리기. 실패하면 화면 내용 그대로 다시 저장
수정하다 창이 닫힘입력 내용을 이 기기에 자동 보관그 매장을 다시 열고 불러오기 → 저장 (그사이 다른 사람이 바꾼 칸과 자동으로 합쳐짐)
사이트·관리자 프로그램 업데이트매장·사진·계정은 별도 저장소(볼륨)에 있어 그대로 유지없음
모든 수정·삭제는 직전 상태가 변경 이력에 남고, 서버가 1시간마다(변경이 있을 때)·매일·업데이트 때마다 전체 백업을 만듭니다.

7변경 이력·되돌리기

  1. 매장 수정 화면 위쪽의 변경 이력을 누릅니다.
  2. 누가, 언제, 어떤 칸을 무엇에서 무엇으로 바꿨는지 보입니다 (매장당 최근 60개).
  3. 잘못 바뀌었으면 원하는 줄의 이 상태로 되돌리기를 누릅니다.

되돌리기 전 상태도 이력에 남으므로, 되돌리기를 잘못 눌러도 다시 돌아갈 수 있습니다. 본인 담당 매장만 되돌릴 수 있고, 관리자는 모든 매장이 됩니다.

8문의·통화 알림

문의함

  • 사이트의 창업 의뢰·양도 의뢰·문자 상담이 여기로 들어옵니다. 내 담당 매장 문의와 담당 미배정 문의가 보입니다.
  • 문의를 눌러 연락처를 확인하고 ☎로 전화합니다. 처리 상태를 바꾸고 처리 메모를 남겨 주세요.
새 문의→연락 중→완료또는스팸

통화 알림

고객이 매장 페이지에서 담당자 전화 연결을 누르면 기록이 남고, 문자 발송이 설정되어 있으면 담당자 휴대폰으로 매장 링크 문자가 갑니다. 통화 직후 어떤 매장을 보고 전화했는지 바로 알 수 있습니다.

9메시지·공지

  • 담당 변경 요청, 매장 확인 요청 등은 메시지로 남기세요. 받는 사람을 고르고 보냅니다. 문자도를 켜면 휴대폰 문자로도 갑니다.
  • 관리자 공지는 대시보드와 메시지·공지에 표시됩니다. 읽은 뒤 확인을 눌러 주세요 (관리자가 읽음 수를 봅니다).
  • 읽지 않은 메시지 수는 왼쪽 메뉴에 숫자로 표시됩니다.

10내 정보·비밀번호

내 정보 → 정보·비밀번호 수정에서 이름·휴대폰·카카오·소개·사진과 비밀번호를 바꿉니다. 비밀번호를 바꿀 때는 현재 비밀번호가 필요합니다. 잊어버렸다면 관리자에게 초기화를 요청하세요.

11직원 계정 관리자

  • 직원 추가: 아이디(영문·숫자 3~20자), 이름, 휴대폰, 첫 비밀번호를 넣습니다. 직원에게 아이디·비밀번호를 전달하고 첫 로그인 후 바꾸게 하세요.
  • 비밀번호 초기화: 직원 줄의 수정에서 새 비밀번호를 넣고 저장합니다.
  • 퇴사 처리: 수정에서 활성을 해제하면 로그인만 막히고, 계정·매장·문의 기록은 그대로 남습니다.
  • 매장 이관: 퇴사·휴가 직원의 담당 매장과 진행 중 문의를 다른 직원에게 한 번에 넘깁니다. 받는 직원에게 알림 메시지가 갑니다.

12매장 일괄 관리 관리자

  • 매장 관리에서 체크박스로 여러 건을 고른 뒤 담당 변경·상태 변경·검증 완료 표시를 한 번에 적용합니다. 바뀐 매장은 모두 변경 이력에 남습니다.
  • 필터: 담당 전체 / 내 매장 / 미배정 / 비활성 직원, 상태, 출처. 검색은 번호·제목·브랜드·지역·담당자로 합니다.
  • 예시 매장: 사이트에 예시 매장 12건이 보이는 동안 목록 위에 안내가 나옵니다. 실제 매장을 충분히 등록한 뒤 예시 매장 모두 내리기를 누르세요 (삭제됨 목록에서 다시 살릴 수 있음).

13브랜드 관리 관리자

브랜드별 업종, 평균 지출 비율(재료비·인건비·월비용 등), 소개를 관리합니다. 고친 값은 다음 등록부터 자동 입력값으로 쓰이고, 이미 등록된 매장 숫자는 바뀌지 않습니다. 새 브랜드는 + 브랜드 추가에서 이름과 영문 주소(slug, 예: mega-coffee)를 넣습니다.

14사이트 정보·문자 발송 관리자

  • 사이트 정보: 대표번호·이메일·상담 시간. 대표번호를 비워 두면 사이트에 전화 버튼 대신 문의 버튼이 나옵니다. 상호·대표·사업자번호·주소는 사업자등록증 기준으로 고정입니다.
  • 방문 분석·검색엔진 연결: GA4·태그 매니저·네이버 애널리틱스·Clarity ID, 구글·네이버·빙 소유확인 코드를 넣으면 모든 페이지에 자동으로 들어갑니다.
  • 통화 알림·문의 문자: 알리고 또는 솔라피 키와 등록된 발신번호를 넣고 내 번호로 테스트 발송으로 확인합니다. 설정 전에는 기록만 남고 문자는 가지 않습니다.
  • 사이트 반영: 보통 자동이지만, 바로 반영하려면 지금 사이트 반영을 누릅니다. 마지막 반영 결과(정상/실패)가 표시됩니다.
  • 활동 기록: 로그인·등록·수정·삭제·백업 등 최근 활동이 보입니다.

15백업·복원 관리자

자동 백업 (설정·백업 → 자동 백업 · 데이터 안전)

언제보관 개수
사이트 업데이트·서버 재시작 때최근 10개
1시간마다 (그사이 변경이 있을 때만)최근 48개 (약 2일)
매일 1회최근 45일
복원하기 직전최근 10개
지금 백업 만들기로 직접최근 20개
  • 맨 위 안전 표시는 데이터가 업데이트 때 지워지지 않는 저장소(볼륨)에 있다는 뜻입니다. 위험이 보이면 즉시 개발 담당에게 알려 주세요.
  • 내려받기: 그 시점 백업 파일(JSON)을 PC에 저장합니다.
  • 이 시점으로 되돌리기: 전체 데이터를 그 시점으로 되돌립니다. 그 이후 등록·수정한 내용은 사라지므로, 한 매장만 문제라면 변경 이력으로 그 매장만 되돌리세요. 되돌리기 직전 상태는 자동으로 백업되어 다시 돌아갈 수 있습니다.

백업 파일로 복원 · 매장 불러오기

  • 합치기: 파일의 내용을 더합니다. 같은 번호는 파일 내용으로 덮어쓰고, 덮어쓴 매장의 이전 상태는 변경 이력에 남습니다.
  • 전체 교체: 현재 데이터를 파일 내용으로 바꿉니다 (직원 계정은 유지).
  • 매장만 담긴 JSON 배열 파일을 올리면 매장 불러오기로 처리됩니다.
서버 백업과 별개로, 개발 PC에서 사이트를 업데이트할 때마다 운영 데이터가 PC의 backups 폴더에도 자동 저장됩니다 (최근 60개). 그래도 월 1회는 내려받기로 따로 보관해 두세요.

관리자 비밀번호를 잊어버렸을 때

Railway → changupguide 서비스 → Variables에서 ADMIN_RESET_PASSWORD에 새 비밀번호(8자 이상)를 넣으면, 재배포 후 admin 계정 비밀번호가 그 값으로 바뀝니다. 같은 값은 한 번만 적용됩니다.

16자주 묻는 질문

저장했는데 사이트에 안 보여요

반영까지 10초~1분 걸립니다. 상태가 공개인지 확인하고, 사이트를 새로고침하세요. 그래도 안 되면 관리자가 설정의 마지막 반영 결과를 확인합니다.

"다른 직원이 같은 항목을 먼저 고쳤습니다"가 떠요

같은 칸을 둘이 다르게 고친 경우입니다. 안내에 두 값이 나오니, 내 값이 맞으면 [확인], 확실하지 않으면 [취소] 후 상대와 메시지로 확인하세요. 다른 칸은 이미 자동으로 합쳐집니다.

"서버 응답을 기다리는 중…"이 떠요

사이트 업데이트 등으로 서버가 잠깐 재시작하는 중입니다. 자동으로 다시 시도하니 화면을 닫지 말고 기다리세요. 끝내 실패해도 입력 내용은 화면에 그대로 있으니 다시 저장하면 됩니다.

매장을 실수로 지웠어요

매장 관리 상태 필터에서 삭제됨을 고르고 그 매장을 열어 상태를 공개로 바꾸거나, 변경 이력에서 삭제 직전 상태로 되돌리세요.

숫자를 잘못 고쳐 저장했어요

변경 이력에서 고치기 전 줄의 이 상태로 되돌리기를 누르세요.

다른 직원 매장을 고쳐야 해요

담당자에게 메시지로 요청하거나, 관리자에게 담당 변경을 요청하세요. 관리자는 모든 매장을 고칠 수 있습니다.

로그인이 안 돼요

아이디는 대소문자를 구분합니다. 비밀번호를 잊었으면 관리자에게 초기화를 요청하세요. 퇴사 처리(비활성)된 계정은 로그인되지 않습니다.

17꼭 지켜주세요

  • 정확한 위치·상호가 드러나는 사진이나 문구는 올리지 않습니다.
  • 매출·수익·권리금은 양도인에게 확인한 숫자만 적습니다. 모르는 칸은 비워 두면 자동 계산되거나 "협의"로 표시됩니다.
  • 고객 연락처 등 문의 정보는 상담 목적으로만 쓰고, 캡처·외부 공유를 하지 않습니다.
  • 계정은 본인만 사용하고, 공용 PC에서는 로그아웃합니다.
  • 무단 접근과 자료 외부 유출은 금지됩니다.
